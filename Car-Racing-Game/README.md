# 🏎️ Python Car Racing Game

## Project Overview

An interactive 2D car racing game developed using Python and Pygame. Players control a car, avoid incoming vehicles and earn points while the difficulty progressively increases.

## Features

- Interactive 2D graphics
- Real-time car movement
- Animated racing track
- Random enemy car generation
- Automatic collision detection
- Progressive difficulty
- Real-time score tracking
- Game restart functionality

## Technologies Used

- Python
- Pygame
- Random Module

## Installation

Install the required library:

```bash
pip install pygame
```

## How to Run

```bash
python main.py
```

## Game Controls

| Key | Action |
|---|---|
| Left Arrow | Move Left |
| Right Arrow | Move Right |
| R | Restart after Game Over |
| ESC | Exit Game |
